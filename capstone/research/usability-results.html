Usability Report

Significant Observations

Users thought that...

  • there wasn't enough context before being prompted to answer questions
  • they were sent to the final screen too quickly because there wasn't enough build-up
  • the written summary visually felt like an afterthought

Addressing the Questions and Feedback

Aspects that need improvement:

  • More narrative build-up to the color matrix
  • Increase color contrast between some of the blocks in the matrix
  • Choose a different font that allows boldness to stand out more clearly
  • Make the summary stand out more, possibly make it a separate screen

User interaction and impact:

  • Users had no issues navigating the interface
  • The right message was conveyed effectively, but they need more of a push into the right direction

Next steps:

I will focus on improving the narrative flow and visual hierarchy of the project. I want to make sure that users are fully engaged with the story and understand the context before they see the final visualizations. I also want to explore ways to make the summary more visually impactful, possibly by giving it its own dedicated screen or using more dynamic typography and layout techniques.
