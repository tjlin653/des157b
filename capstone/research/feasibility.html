Feasibility Report

This report evaluates the technical scope, required technologies, planned features, and potential development challenges for my capstone project, Where Your Life Goes.

Interactive Habit Questionnaire

Planned Features:

  • User inputs for screen time, social media usage, and notification frequency
  • Interactive sliders and dynamic value updates
  • Personalized future projections based on user habits

Technologies Required:

  • HTML forms and semantic structure
  • CSS styling and responsive layout design
  • JavaScript DOM manipulation and event listeners

Skill Assessment:

I am already comfortable with HTML, CSS, and JavaScript event handling, so this feature is highly achievable within the project timeframe. Most of the difficulty will involve refining the visual design and making the interactions feel polished and immersive rather than technically difficult.

Attention Fragmentation Visualization

Planned Features:

  • Animated notifications interrupting the screen
  • A shrinking or fragmenting focus object representing user attention
  • Motion-based visual storytelling showing distraction over time

Technologies Required:

  • JavaScript animation logic
  • CSS animations and transitions
  • Possibly GSAP for smoother motion and timing control

Skill Assessment:

I have some experience with animation and interactive JavaScript projects, but this feature will likely require the most experimentation and refinement. I believe I can reasonably become skilled enough with GSAP and animation timing within the project timeframe because the animations are conceptually simple, even if they require careful visual tuning.

Data Visualization and Future Projections

Planned Features:

  • Visualizations of years spent online
  • Projected lifetime interruptions and ad exposure
  • Animated statistics and responsive visual outputs

Technologies Required:

  • JavaScript calculations and JSON datasets
  • Possibly D3.js or Chart.js for advanced visualizations
  • Responsive CSS layouts and transitions

Skill Assessment:

I have limited experience with advanced data visualization libraries, so I may simplify some visualizations if implementation becomes too time consuming. However, I believe I can create strong custom visualizations using standard JavaScript, CSS, and SVG elements without relying heavily on complex frameworks.

Development Challenges and Project Changes

One major challenge I uncovered during development planning is that my original concept focused too heavily on calculating how much advertising revenue users generate for technology companies. After further research, I realized that this idea was too similar to existing projects such as attentionworth.com and relied on speculative financial estimates that could weaken the conceptual originality of the project.

Because of this, I shifted the project toward visualizing how digital systems consume portions of a person’s life over time rather than focusing primarily on monetary value. This new direction feels more emotionally impactful, more original, and better suited for data visualization and speculative storytelling.
