Project Overview

The Life Calendar is an interactive web-based data narrative that forces users to confront the physical reality of their screen habits over a 50-year horizon. Instead of displaying abstract metrics or standard graphs, the application translates daily screen and sleep data into a high-density grid containing 2,600 unique nodes—each single box representing one week of a user's remaining conscious life.

The Target Audience: Built primarily for digital natives, professionals, and students operating within high-density notification ecosystems, who track screen metrics but experience "data numbness" due to standard, non-contextual log summaries.

Core Project Goals: The system aims to bridge the gap between abstract time tracking and tangible human mortality. By transforming raw numerical variables (e.g., 6.5 hours of daily usage) into a visual footprint, the interface visualizes how digital architecture packages, sections off, and alters our cognitive awareness.

Project Research

To establish credible mathematical models, competitive and comparative analysis was executed across modern time-tracking features (Apple Screen Time, Android Digital Wellbeing) and data-journalism tools (The Center for Humane Technology benchmarks). The findings revealed a critical gap: existing systems act as passive historical logs. They tell users what they did yesterday, but fail to show the compounding trajectory of those habits over time.

How the Research Shifted the Strategy: Initially, the project was conceived as a basic real-time dashboard calculator. However, behavioral data showed that numbers alone fail to change user perspective. The project evolved to leverage structured ratio constants fetched from data layers (such as factoring a 25% social media ad ratio or context-switching taxes based on empirical studies by Dr. Gloria Mark). This shifted the design from a basic utility counter into an narrative-driven progressive disclosure funnel.

Visual Design & Typography

The visual system was constructed using a high-contrast palette (`#060608` void black base) to mimic an immutable terminal environment, establishing a serious mood suited to existential metrics. Colors were assigned strict functional properties: standard digital engagement is mapped in aggressive crimson, sleep uses a passive deep blue, and real-life or reclaimed time uses a bright neon green.

Typography System Decisions: To combat reading fatigue and establish strong informational hierarchy, weight values were maxed out dynamically—pairing strict `400` regular weights for descriptive labels with an impactful `800` heavy bold font for headline callouts. This structural visual contrast ensures numbers stand out instantly even within complex data displays.

User Interface

To reduce initial cognitive load, the application employs a deliberate linear funnel structure. Users cannot view the massive lifecycle matrix until they pass through isolated, data-backed introduction panels and an initial estimation input step. This design protects the user from immediate data saturation, matching standard usability onboarding principles.

Usability Principles: Visibility & Mapping are explicitly addressed on Slide 6 through a dual-state dashboard engine. Users can seamlessly toggle between an "All Activities" overview (broad structural chunks of life) and a granular "Online Activities" view. This view splits the online block into distinct segments: core social scrolling, advertisement consumption, and notification checking. This breakdown maps directly to real-world habits that are usually hidden inside generic tracking categories.

Example Tasks Users Can Complete:

  1. Input daily screen time to automatically build a custom lifelong matrix.
  2. Toggle between the two views that split their life into macro and micro perspectives.
  3. Isolate exactly how many weeks of their life are spent looking at ads.
  4. Hover over individual grid blocks to view localized metrics.

Revisions

The initial design included pie charts instead of a grid-based approach, which felt too boring and unengaging. I was then pivoted to a grid-based design, inspired by the popular "Your Life in Weeks" diagram. Based on this inspiration, I developed a matrix-like approach to visualize the user's online activity in a similar fashion.

Furthermore, early versions lacked narrative elements, leaving users to not feel empowered to make changes. In response to this user feedback, I included a few slides before the user was prompted to input their data. This allowed for more context and build-up to the user's journey. I also implemented actionable steps at the end of the project to leave the user with a sense of control and agency.

Summary

Working on this project highlighted the challenge of keeping interactive data visualizations highly performant. Managing tons of elements inside a live DOM grid requires a strict balance between styling, container layouts, and raw scripting constraints.

The most challenging yet most rewarding aspect was successfully implementing a grid that accurately represented the user's input. I am most proud of the fact that I got the core functionality working as intended.
